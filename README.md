# The Rhynd website

Static rebuild of https://www.therhynd.com with Next.js 16 (App Router),
TypeScript, Tailwind CSS 4, shadcn/ui, React Hook Form and Zod.

```bash
npm install
npm run dev        # http://localhost:3000
npm run check      # lint, typecheck, static build to out/
npm run preview    # serve out/
```

Documentation: [docs/README.md](docs/README.md)
